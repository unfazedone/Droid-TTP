Frequently Asked Questions

Operational guidance for APK review and the separate bundled metadata catalogue.

How do I start an investigation?

Select Start New Investigation, enter a case title and any useful context, then save. Open the case from Cases to manage its samples and notes.

How do I add an APK?

Open a case, choose Add Sample, and select an APK archive containing an Android manifest. It is stored locally and inspected statically; uploaded code is never executed.

Where can I see sample results?

Open a sample from the Samples page or Latest APK Submissions. Review its analysis tabs for manifest, permissions, components, strings, files, and candidate mappings. Static findings are leads, not a malware verdict.

How do I review ATT&CK suggestions?

Inspect each candidate technique alongside its linked evidence. Confirm, reject, or defer it with an analyst rationale; verify the evidence before treating a suggestion as a finding.

How do I use the bundled dataset?

Open Dataset Lab to search package names or hashes, filter by the source label, inspect profiles, and export filtered CSV rows. These records are metadata, not APK analysis results.

How do I export my work?

Use Reports for sample or case HTML/JSON reports. Samples also has an inventory CSV export; Dataset Lab exports the currently filtered dataset profiles.
